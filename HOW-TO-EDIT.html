How to edit your website

You only need to edit one file: EDIT-HERE.js.

1. Open the website

1

Double-click index.html. It opens in your browser.

2. Change a name or message

1

Right-click EDIT-HERE.js and open it with Notepad or Visual Studio Code.

2

Change only the words between quotation marks.

babyFullName: "Adam Fayaz",
babyNickname: "Adam",
3

Save the file, then refresh the website in your browser.

3. Add pregnancy photographs

1

Copy the photograph into the images folder.

2

Give it a simple name such as month-5.jpg.

3

Add its path in EDIT-HERE.js.

photos: [
  "images/month-5-a.jpg",
  "images/month-5-b.jpg"
],

4. Edit your one special letter

Find myLetter in EDIT-HERE.js. Change its title, salutation, message, closing and name. You can also attach one photograph.

myLetter: {
  title: "For my sister",
  salutation: "My dearest sister,",
  message: "Write your letter here.",
  photo: "images/our-sister-photo.jpg"
},

5. Change the theme and background photographs

In EDIT-HERE.js, use defaultTheme: "dark" or defaultTheme: "light". Visitors can still switch modes with the sun/moon button.

You can also add a different wide photograph behind selected chapters. Leave a path empty to keep the built-in magical background.

storyBackgroundImage: "images/story-background.jpg",
pregnancyBackgroundImage: "images/pregnancy-background.jpg",
letterBackgroundImage: "images/letter-background.jpg",
galleryBackgroundImage: "images/gallery-background.jpg",
surpriseBackgroundImage: "images/background.avif",

6. Add video, audio or the family song

Copy MP4 files into videos and your MP3 or OGG recordings into audio.

video: "videos/first-ultrasound.mp4",
audio: [
  "audio/dadvoice1.ogg",
  "audio/dadvoice2.ogg"
],

For the repeating background song, use the exact filename—including capital letters:

familySong: "audio/backgroundsong.mp3",

The background song loops automatically after it is started. It pauses while another audio or video is playing, then continues afterward.

7. Show the birth chapter

After the baby arrives, change this line in EDIT-HERE.js:

babyHasArrived: true,

8. Share or update it

Create a public repository on GitHub, upload everything inside the website folder, then open Settings → Pages. Choose Deploy from a branch, main and /(root). GitHub will give you a phone-friendly link.

To update it later, upload the changed file with the same name, confirm Replace, write a short commit message, and select Commit changes. GitHub Pages normally refreshes after a few minutes.

Privacy reminder: A normal static website link may be opened by anyone who receives it. Add private access before uploading sensitive family photographs or videos.
